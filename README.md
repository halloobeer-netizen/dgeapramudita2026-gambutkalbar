# Peatland Intelligence Platform

**Environmental Survey, Mapping & Spatial Data Management**

Peatland Intelligence Platform is a field-survey and environmental data system for peat ecosystem inventory work in Kapuas Hulu, West Kalimantan. It combines survey progress monitoring, structured environmental records, location-based point data, mapping, document workflows, and secure access in one responsive application.

## Highlights

- Peat ecosystem survey dashboard
- Survey progress monitoring against field targets
- KHG / peat hydrological unit management
- Survey-point records with coordinates and elevation
- Interactive map visualization
- Hydrology and environmental parameter records
- pH, EC, and TDS data management
- Excel import workflow
- Google authentication with Firebase
- Responsive desktop and mobile interface

## Engineering Focus

This project demonstrates the transformation of field survey workflows into a structured digital platform. The application brings together environmental data, spatial information, authentication, data import, responsive interfaces, and operational monitoring.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Mapping:** Leaflet, OpenStreetMap
- **Authentication & Data:** Firebase Authentication, Firebase Realtime Database
- **Data Import:** SheetJS / XLSX
- **Spatial Data:** Geographic coordinates and map-based survey points
- **Deployment:** Static web application architecture

## Core Modules

### Survey Dashboard
Track the number of surveyed points, remaining targets, daily progress, recent records, and overall completion percentage.

### Survey Point Management
Store and review field information including surveyor, date, coordinates, elevation, hydrological conditions, and environmental measurements.

### Spatial Visualization
Display survey-point locations on an interactive map to connect field records with geographic context.

### Environmental Data
Organize peatland survey parameters such as water-table conditions and pH/EC/TDS measurements for field assessment and reporting.

### Secure Access
Protect application access using Google sign-in backed by Firebase Authentication.

## Product Direction

Peatland Intelligence Platform is positioned as an environmental data and spatial intelligence solution that improves the consistency, visibility, and management of field-survey information.
